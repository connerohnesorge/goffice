# Relationship System Research

## Overview

Relationships in OpenXML connect parts to other parts or external resources. The SDK abstracts the raw `.rels` XML through `System.IO.Packaging` APIs.

## Relationship XML Format

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<Relationships xmlns="http://schemas.openxmlformats.org/package/2006/relationships">
  <Relationship Id="rId1"
                Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/hyperlink"
                Target="https://example.com"
                TargetMode="External"/>
  <Relationship Id="rId2"
                Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/media"
                Target="../media/image1.png"/>
</Relationships>
```

## Relationship Types

### Internal vs External

| Type | TargetMode | Storage | Example |
|------|------------|---------|---------|
| Internal | Internal (default) | `_parts` dictionary | slide → slide layout |
| External | External | `_referenceRelationships` | hyperlinks to URLs |

### Relationship Class Hierarchy

```
ReferenceRelationship (abstract)
  ├── HyperlinkRelationship
  ├── ExternalRelationship
  └── DataPartReferenceRelationship (abstract)
        ├── MediaReferenceRelationship
        ├── AudioReferenceRelationship
        └── VideoReferenceRelationship
```

## Key Relationship Type Constants

| Type | URI | Purpose |
|------|-----|---------|
| Hyperlink | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/hyperlink` | External/internal links |
| Media | `http://schemas.microsoft.com/office/2007/relationships/media` | General media files |
| Audio | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/audio` | Audio files |
| Video | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/video` | Video files |
| Image | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/image` | Image files |
| Slide | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/slide` | Presentation slides |
| OfficeDocument | `http://schemas.openxmlformats.org/officeDocument/2006/relationships/officeDocument` | Main document part |

## Relationship ID Generation

- Format: `rId1`, `rId2`, etc.
- Auto-generated by System.IO.Packaging if not specified
- IDs must be unique within a part's relationship set

## PartRelationshipsFeature Implementation

```csharp
class PartRelationshipsFeature : IPartRelationshipsFeature, IReferenceRelationshipsFeature
{
    private Dictionary<string, OpenXmlPart>? _parts;
    private Dictionary<string, ReferenceRelationship>? _referenceRelationships;

    // Lazy loading: loads relationships on first access
    private Dictionary<string, OpenXmlPart> RelationshipMap {
        get {
            if (_parts is null) {
                LoadReferencedPartsAndRelationships();
            }
            return _parts;
        }
    }
}
```

## Lazy Loading Process

1. Get relationships from `Relationships.GetEnumerator()`
2. For each relationship:
   - **Hyperlinks**: Create `HyperlinkRelationship` wrapper
   - **Data Parts**: Create appropriate `DataPartReferenceRelationship`
   - **Internal Parts**: Create or retrieve `OpenXmlPart`
   - **External**: Create `ExternalRelationship` wrapper
3. Store in appropriate dictionary

## Go Implementation Considerations

1. **Implement lazy relationship loading** with dictionary caching
2. **Support both internal and external relationships** via type switching
3. **Auto-generate relationship IDs** with incrementing counter
4. **Resolve relative URIs** using base part URI
5. **Separate relationship storage** for parts vs reference relationships
6. **Use interface abstraction** for different relationship types
